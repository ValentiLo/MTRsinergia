# Термины по лекции «Понятие материально-технических условий. Роль в разработке игр»

Список ключевых терминов с объяснением.

---

## Основные понятия

**Материально-технические условия (МТУ)**  
Совокупность ресурсов, необходимых для выполнения проекта: оборудование, программное обеспечение, помещения, инфраструктура, расходные материалы.

**Аппаратное обеспечение (Hardware)**  
Физические устройства: компьютеры, видеокарты, мониторы, периферия, VR-шлемы, серверы.

**Программное обеспечение (Software)**  
Программы и инструменты: операционные системы, игровые движки, редакторы, IDE.

**Инфраструктура**  
Сеть, серверы, хранилища данных, системы сборки и развёртывания.

**Расходные материалы**  
Бумага, картриджи, носители информации, кабели — то, что расходуется в процессе работы.

---

## Аппаратное обеспечение

**Процессор (CPU)**  
Центральный процессор — «мозг» компьютера. Отвечает за вычисления, логику, физику в играх. Чем больше ядер и выше частота, тем быстрее работает сборка и отладка.

**Оперативная память (ОЗУ, RAM)**  
Временное хранилище данных. Чем больше ОЗУ, тем больше ассетов и сцен можно держать открытыми одновременно.

**Видеокарта (GPU)**  
Графический процессор. Отвечает за рендеринг графики, работу с текстурами, шейдерами. Для разработки игр нужна мощная дискретная видеокарта.

**Накопитель (HDD, SSD, NVMe)**  
Устройство хранения данных. SSD и NVMe быстрее HDD, что ускоряет загрузку ассетов и сборку проекта.

**Монитор**  
Устройство вывода. Для разработки важны разрешение, цветопередача и частота обновления.

**Периферия**  
Дополнительные устройства: клавиатура, мышь, геймпад, графический планшет.

**Графический планшет**  
Устройство для рисования стилусом. Используется художниками для создания 2D-графики и текстур.

**VR-шлем**  
Устройство виртуальной реальности. Используется для тестирования VR-игр и приложений.

**Сервер**  
Мощный компьютер для хранения данных, сборки проектов, хостинга многопользовательских игр.

**Ферма для сборки**  
Группа серверов, которые параллельно компилируют проект. Используется в крупных студиях для ускорения сборки.

---

## Программное обеспечение

**Операционная система (ОС)**  
Базовое ПО: Windows, Linux, macOS. Для разработки игр чаще всего используют Windows.

**Игровой движок**  
Программная среда для создания игр. Содержит готовые компоненты: физику, рендеринг, звук, анимацию. Примеры: Unity, Unreal Engine, Godot.

**Unity**  
Игровой движок. Популярен для 2D и 3D игр, мобильных проектов. Язык — C#.

**Unreal Engine**  
Игровой движок. Используется для AAA-проектов с фотореалистичной графикой. Язык — C++, визуальные Blueprints.

**Godot**  
Открытый игровой движок. Бесплатный, лёгкий. Язык — GDScript, C#.

**3D-редактор**  
Программа для создания 3D-моделей: Blender, Maya, 3ds Max, ZBrush.

**2D-редактор**  
Программа для создания 2D-графики: Photoshop, Krita, Aseprite.

**Редактор анимации**  
Программа для создания анимаций: Spine, DragonBones, Mixamo.

**Звуковой редактор**  
Программа для работы со звуком: Audacity, FMOD, Wwise.

**IDE (Integrated Development Environment)**  
Среда разработки: Visual Studio, Rider, VS Code. Используется для написания кода.

**Система контроля версий (VCS)**  
Инструмент для отслеживания изменений в коде: Git, Perforce.

**Баг-трекер**  
Инструмент для учёта ошибок: Jira, Trello, GitHub Issues.

**CI/CD**  
Непрерывная интеграция и доставка. Автоматизация сборки, тестирования и развёртывания: Jenkins, GitHub Actions.

## Инфраструктура

**Сеть**  
Совокупность устройств для обмена данными: роутеры, коммутаторы, кабели.

**NAS (Network Attached Storage)**  
Сетевое хранилище данных. Используется для общих файлов команды.

**Облачное хранилище**  
Удалённое хранилище: Google Drive, Dropbox, Яндекс.Диск.

**Резервное копирование**  
Создание копий данных для защиты от потери.

**Тестовый стенд**  
Оборудование для проверки игры на разных конфигурациях: ПК, консоли, мобильные устройства.

---

## Организация работы

**Рабочее место**  
Место сотрудника с оборудованием: компьютер, монитор, периферия.

**Эргономика**  
Наука о комфортной и безопасной организации рабочего пространства.

**Open space**  
Открытое офисное пространство без стен между рабочими местами.

**Переговорная**  
Помещение для встреч и обсуждений.

**Команда разработки**  
Группа специалистов: программисты, художники, дизайнеры, тестировщики, менеджеры.

---

## Типы студий

**Инди-студия**  
Небольшая команда (2–10 человек). Ограниченный бюджет. Простые МТУ.

**Средняя студия**  
20–50 человек. Средний бюджет. Серьёзное оборудование.

**AAA-студия**  
200+ человек. Крупный бюджет. Мощная инфраструктура: фермы сборки, motion-capture, звукозапись, VR-лаборатории.

---

## Экономика

**Бюджет проекта**  
Сумма средств на разработку: закупка, лицензии, зарплаты, обслуживание.

**Лицензия на ПО**  
Право использования программы. Может быть бесплатной (Godot), платной (Unity Pro), подписочной (Adobe).

**Расходные материалы**  
Ресурсы, которые расходуются: бумага, картриджи, носители.

**Запас бюджета**  
Резерв 20–30% на непредвиденные расходы.
