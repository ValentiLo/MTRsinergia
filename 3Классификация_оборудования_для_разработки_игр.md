# Лекция: Классификация оборудования для разработки игр

**Дисциплина:** Материально-технические условия реализации проектов на основе компьютерных игр  
**Раздел 1.** Введение  
**Тип занятия:** лекция (2 ч)

---

## 1. Цели и задачи

**Цель:** систематизировать знания об оборудовании, которое используется при разработке игр, и понять, для каких задач нужен каждый тип устройств.

**Задачи:**
- рассмотреть основные классы оборудования;
- понять назначение каждого класса;
- научиться подбирать оборудование под задачи;
- познакомиться с примерами из индустрии.

**Формируемые компетенции:**
- **ОК 01** — выбирать способы решения задач профессиональной деятельности;
- **ОК 02** — использовать современные средства поиска и анализа информации;
- **ПК 6.1** — использовать популярные платформы для сборки и развёртывания контента.

---

## 2. Зачем нужна классификация

Оборудование для разработки игр **очень разнородно**. Одно дело — написать простой 2D-платформер на ноутбуке, другое — создать AAA-проект с motion-capture и VR.

**Классификация помогает:**
- понять, что именно нужно для конкретного проекта;
- правильно распределить бюджет;
- не купить лишнего;
- не забыть важное.

Классифицировать оборудование можно **по нескольким признакам**:
- по назначению;
- по роли в проекте;
- по масштабу;
- по типу решаемых задач.

Рассмотрим **основную классификацию — по назначению**.

---

## 3. Основная классификация по назначению

### 3.1. Рабочие станции разработчиков

**Что это:** основные компьютеры, на которых работают программисты, художники, дизайнеры, аналитики.

**Для чего:**
- написание кода,
- создание 3D-моделей,
- работа с текстурами,
- сборка проекта.

**Требования:**

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| Процессор | Intel Core i5 | Intel Core i7/i9, AMD Ryzen 7/9 |
| ОЗУ | 16 ГБ | 32–64 ГБ |
| Видеокарта | GTX 1660 | RTX 3060+ |
| Накопитель | SSD 512 ГБ | SSD NVMe 1 ТБ + HDD 2 ТБ |

**Разновидности:**
- **ПК для программиста** — упор на процессор и ОЗУ.
- **ПК для художника** — упор на видеокарту и монитор.
- **ПК для звукорежиссёра** — упор на аудиоинтерфейс.

---

### 3.2. Серверное оборудование

**Что это:** мощные компьютеры для хранения данных, сборки проектов, хостинга.

**Для чего:**
- сборка проекта (сборка может занимать часы),
- хранение больших объёмов данных,
- хостинг многопользовательских игр,
- CI/CD (автоматизация).

**Типы серверов:**

| Тип | Для чего |
|-----|----------|
| **Сервер сборки** | Компиляция проекта |
| **Файловый сервер** | Хранение ассетов |
| **Игровой сервер** | Хостинг многопользовательских игр |
| **Сервер CI/CD** | Автоматизация |

**Ферма для сборки** — группа серверов, которые параллельно компилируют проект. Используется в крупных студиях.

---

### 3.3. Оборудование для захвата движения (Motion Capture)

**Что это:** комплекс устройств для записи движений актёров.

**Для чего:**
- реалистичная анимация персонажей,
- запись боевых сцен,
- лицевая анимация.

**Состав:**
- **Камеры** — от 8 до 100+ штук.
- **Костюм с маркерами** — на актёре.
- **Специализированное ПО** — обработка данных.
- **Студия** — помещение с камерами.

**Примеры систем:**
- Vicon,
- OptiTrack,
- Xsens (безкамерная).

⚠️ **Дорогое удовольствие** — доступно крупным студиям.

---

### 3.4. Звукозаписывающее оборудование

**Что это:** комплекс для записи и обработки звука.

**Для чего:**
- запись музыки,
- озвучка персонажей,
- звуковые эффекты,
- микширование.

**Состав:**
- **Микрофоны** — конденсаторные, динамические.
- **Аудиоинтерфейс** — подключение к ПК.
- **Микшерный пульт** — управление звуком.
- **Студийные мониторы** — колонки.
- **Наушники** — для контроля.
- **Звукоизолированная студия**.

---

### 3.5. Оборудование для VR/AR

**Что это:** устройства для разработки и тестирования VR/AR-проектов.

**Для чего:**
- создание VR-игр,
- тестирование погружения,
- отладка контроллеров.

**Состав:**
- **VR-шлем** — Oculus/Meta Quest, HTC Vive, Valve Index.
- **Контроллеры** — для рук.
- **Трекеры** — для тела.
- **Беговая дорожка** — для передвижения.
- **Перчатки с обратной связью** — тактильные ощущения.

⚠️ **Обязательно для VR-проектов.**

---

### 3.6. Тестовое оборудование

**Что это:** устройства для проверки игры на разных платформах.

**Для чего:**
- тестирование на консолях,
- проверка на мобильных,
- проверка на разных ПК.

**Состав:**
- **Консоли** — PlayStation, Xbox, Nintendo Switch.
- **Мобильные устройства** — Android, iOS.
- **ПК разных конфигураций** — от слабых до мощных.
- **Тестовые стенды** — специальные лаборатории.

---

### 3.7. Периферия и устройства ввода

**Что это:** устройства для взаимодействия с компьютером.

**Для чего:**
- работа с графикой,
- тестирование управления,
- удобство работы.

**Состав:**

| Устройство | Для чего |
|-----------|----------|
| **Клавиатура** | Программирование, набор текста |
| **Мышь** | Работа с интерфейсом |
| **Графический планшет** | Рисование, 2D-графика |
| **Геймпад** | Тестирование игр |
| **Руль, джойстик** | Тестирование симуляторов |
| **MIDI-клавиатура** | Создание музыки |

---

### 3.8. Устройства вывода

**Что это:** устройства для отображения и вывода результата.

**Состав:**

| Устройство | Для чего |
|-----------|----------|
| **Монитор** | Основной вывод |
| **Второй монитор** | Дополнительное пространство |
| **Проектор** | Презентации |
| **Интерактивная доска** | Демонстрации |
| **Студийные мониторы** | Контроль звука |
| **Принтер** | Документация |

---

### 3.9. Сетевое оборудование

**Что это:** устройства для связи компьютеров в сеть.

**Для чего:**
- обмен данными,
- доступ к серверам,
- тестирование многопользовательских игр.

**Состав:**
- **Роутеры**,
- **Коммутаторы**,
- **Кабели** (витая пара, оптоволокно),
- **Wi-Fi точки доступа**.

---

### 3.10. Оборудование для хранения данных

**Что это:** устройства для хранения больших объёмов информации.

**Для чего:**
- хранение ассетов,
- резервное копирование,
- общий доступ команды.

**Состав:**
- **NAS** — сетевое хранилище.
- **СХД** — системы хранения данных.
- **Внешние диски** — для переноса.
- **Облачные сервисы** — Google Drive, Dropbox.

## 4. Классификация по роли в проекте

| Роль | Оборудование |
|------|--------------|
| **Программист** | Рабочая станция, второй монитор, клавиатура |
| **Художник 3D** | Мощная станция, планшет, монитор с хорошей цветопередачей |
| **Художник 2D** | Графический планшет, монитор |
| **Аниматор** | Motion-capture, планшет |
| **Звукорежиссёр** | Аудиоинтерфейс, микрофоны, мониторы |
| **Тестировщик** | Консоли, мобильные, ПК разных конфигураций |
| **DevOps** | Серверы, сетевое оборудование |
| **Продюсер** | ПК, проектор, переговорная |

## 5. Классификация по масштабу студии

| Тип студии | Оборудование |
|------------|--------------|

| **AAA** | Сотни станций, фермы сборки, motion-capture, звукозапись, VR-лаборатория |

## 7. Как подобрать оборудование

**Шаги:**

1. **Определить тип проекта** — 2D/3D, ПК/мобильная, VR/AR.
2. **Выбрать движок** — Unity, Unreal, Godot.
3. **Оценить команду** — сколько человек, какие роли.
4. **Составить список задач** — что нужно делать.
5. **Подобрать оборудование** — под каждую задачу.
6. **Учесть бюджет** — закупка + обслуживание.
7. **Заложить запас** — 20–30%.

## 8. Типичные ошибки

| Ошибка | Последствия |
|--------|-------------|
| Экономия на видеокартах | Художники не могут работать |
| Мало ОЗУ | Постоянные тормоза |
| Один сервер сборки | Очередь, срыв сроков |
| Нет тестовых устройств | Баги на релизе |
| Нет motion-capture | Примитивная анимация |
| Плохой монитор | Неверные цвета |
| Нет резервного копирования | Потеря данных |

## 9. Итоги

- **Оборудование классифицируется** по назначению, роли, масштабу.
- **Основные классы:** рабочие станции, серверы, motion-capture, звукозапись, VR/AR, тестовое, периферия, вывод, сеть, хранение.
- **Для инди** — достаточно личного ПК.
- **Для AAA** — нужны фермы сборки, motion-capture, звукозапись.
- **Подбор оборудования** зависит от проекта и команды.
