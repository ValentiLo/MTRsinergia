## Вариант 1. «Бюджет инди-студии»

**Задание:** Вы — продюсер инди-студии из 3 человек (программист, 3D-художник, геймдизайнер). Вы разрабатываете небольшую игру на Unreal Engine 5 для ПК. Бюджет на техническое обеспечение — **500 000 рублей**.

**Что нужно сделать:**
1.  Составьте смету расходов на техническое обеспечение (таблица в Excel/Google Sheets).
2.  Обоснуйте выбор: покупка «железа» или аренда облачных мощностей.
3.  Учтите лицензии на ПО (UE5 бесплатен до релиза, но что с остальным?).
4.  Заложите резерв на непредвиденные расходы (не менее 10%).
5.  Оформите результат в виде короткого отчета (1–2 страницы) с таблицей и выводами.

**Критерии оценки:** реалистичность цен, учет скрытых расходов, обоснование выбора.

## Вариант 2. «Обоснование закупки рабочей станции»

**Задание:** Студия закупает новую рабочую станцию для 3D-художника, который работает в Maya и Substance Painter. Бюджет на один ПК — **от 150 000 до 250 000 рублей**.

**Что нужно сделать:**
1.  Составьте конфигурацию ПК (процессор, видеокарта, ОЗУ, SSD, монитор, периферия) с указанием конкретных моделей и цен.
2.  Обоснуйте выбор каждого компонента с точки зрения задач художника.
3.  Сравните два варианта: покупка готовой сборки (например, у DigitalRazor) vs самостоятельная сборка. Что выгоднее?
4.  Укажите, какие лицензии на ПО потребуются дополнительно.

**Критерии оценки:** соответствие конфигурации задачам, актуальность цен, грамотное обоснование.

## Вариант 3. «Переход на удаленную работу»

**Задание:** Студия из 10 человек (5 разработчиков, 3 художника, 2 тестировщика) переходит на полностью удаленную работу. Раньше все работали в офисе на общем «железе».

**Что нужно сделать:**
1.  Определите, какое техническое обеспечение нужно каждому сотруднику дома (минимальные требования).
2.  Рассмотрите два сценария: (а) студия закупает оборудование сотрудникам; (б) сотрудники работают на своем «железе», а студия компенсирует расходы.
3.  Посчитайте бюджет для каждого сценария на год.
4.  Предложите решение для организации совместной работы (облачные хранилища, удаленные серверы для сборок).
5.  Сделайте вывод: какой сценарий выгоднее и почему.

**Критерии оценки:** полнота учета расходов, реалистичность цен, обоснование выбора.

## Вариант 4. «Лицензионная политика»

**Задание:** Студия использует нелицензионное ПО (Maya, Substance Painter, Perforce) для разработки коммерческой игры. Юрист предупреждает о рисках.

**Что нужно сделать:**
1.  Составьте список используемого ПО и рассчитайте стоимость легальных лицензий на год для команды из 5 человек.
2.  Предложите бесплатные или более дешевые аналоги (Blender вместо Maya, Git LFS вместо Perforce и т.д.).
3.  Оцените риски использования пиратского ПО (штрафы, репутационные потери, срыв сроков).
4.  Сделайте вывод: стоит ли переходить на легальное ПО и как это сделать с минимальными затратами.

**Критерии оценки:** знание рынка ПО, реалистичность цен, аргументированность выводов.

## Вариант 5. «Серверная инфраструктура для тестирования»

**Задание:** Студия готовится к закрытому бета-тестированию многопользовательской игры. Ожидается 1000 игроков одновременно. Нужно организовать серверную инфраструктуру на 1 месяц.

**Что нужно сделать:**
1.  Сравните два варианта: аренда облачных серверов (AWS, Vagon, Selectel) vs покупка собственного сервера.
2.  Рассчитайте стоимость каждого варианта на месяц.
3.  Учтите затраты на администрирование, резервное копирование, защиту от DDoS.
4.  Сделайте вывод: что выгоднее для студии и почему.

**Критерии оценки:** понимание облачных технологий, реалистичность расчетов, учет сопутствующих расходов.

## Вариант 6. «Анализ кейса: провал из-за экономии»

**Задание:** Найдите в открытых источниках пример игрового проекта, который пострадал из-за недостаточного технического обеспечения (например, срыв сроков из-за слабого «железа», проблемы с серверами на релизе, последствия использования пиратского ПО).

**Что нужно сделать:**
1.  Кратко опишите ситуацию (что произошло, какая студия, какая игра).
2.  Проанализируйте, какие статьи бюджета технического обеспечения были недооценены.
3.  Предложите, как можно было бы избежать проблемы (какие расходы нужно было заложить).
4.  Сделайте выводы для будущих проектов.

**Критерии оценки:** качество анализа, глубина выводов, связь с теорией бюджетирования.

## Вариант 7. «Бюджет для кроссплатформенного проекта»

**Задание:** Студия разрабатывает игру для ПК, PlayStation 5 и Nintendo Switch. Бюджет на техническое обеспечение — **1 500 000 рублей**.

**Что нужно сделать:**
1.  Определите, какое оборудование нужно для разработки и тестирования на каждой платформе (dev-kits, тестовые консоли).
2.  Составьте смету расходов (таблица).
3.  Учтите лицензии на платформы (SDK, сертификация).
4.  Предложите, на чем можно сэкономить без потери качества.
5.  Сделайте вывод: какие платформы обходятся дороже всего в техническом обеспечении и почему.

**Критерии оценки:** знание платформенных требований, реалистичность цен, обоснование выбора.

## 📋 Общие требования ко всем вариантам

1.  **Формат:** отчет в Word (2–4 страницы) + таблица в Excel (если требуется расчет).
2.  **Источники:** указывайте ссылки на сайты, откуда взяты цены (DNS, Citilink, DigitalRazor, официальные сайты ПО).
3.  **Актуальность:** цены должны быть актуальными на момент выполнения задания.
4.  **Обоснование:** каждое решение должно быть аргументировано, а не просто «взято из головы».
5.  **Выводы:** в конце отчета — краткое резюме (что удалось учесть, какие сложности возникли).
